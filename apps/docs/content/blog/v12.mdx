## 新特性

Fumadocs v12 主要致力于改进用户界面，优先考虑内容和阅读体验。

### 全新界面

在观察了像 https://turbo.build 这样的大型文档站点后，我发现导航栏在屏幕上占据了过多空间，而它只包含博客、展示、GitHub 等链接。
这些链接与文档内容并不直接相关，将它们放在屏幕顶部并不能带来更好的阅读体验。

现在所有这些链接都已移至侧边栏，使文档呈现简洁、极简的视图。

![预览](/blog/v12.png)

我还注意到随着内容增长，文档开始显得杂乱。为了改善这一点，侧边栏现在默认包含边框和背景。
这有助于读者更轻松地区分导航元素和内容。

侧边栏将始终位于屏幕左侧，在大尺寸视口中拥有更大的空间。

我相信新界面仍有改进空间。欢迎报告界面问题或留下反馈！

### 更好的多页面树

我们在 Fumadocs 的早期版本中就支持了多页面树。然而，缺乏适当的解释和配置指南。
过去，您需要实现一个导航元素来在页面树之间切换，并将文件夹标记为根文件夹。

现在，您可以直接使用 `<RootToggle />` 组件，并且文档对其有更好的解释。

### 页面树后处理器

您现在可以通过 Source API 轻松地向页面树附加属性。

```ts
import { loader } from 'fumadocs-core/source';

export const utils = loader({
  pageTree: {
    attachFile(node) {
      // modify the node
      return node;
    },
  },
});
```

### 改进的国际化支持

语言切换功能现已添加到 Docs Layout 中。

```tsx
import { DocsLayout } from 'fumadocs-ui/layouts/docs';

export default function Layout({ children }: { children: React.ReactNode }) {
  return <DocsLayout i18n>{children}</DocsLayout>;
}
```

请注意，`<LanguageSelect />` 组件现已被 `<LanguageToggle />` 取代，请确保移除对旧组件的引用。

## 重大变更

### 用户界面

从 Root Provider 中移除已弃用的选项 `enableThemeProvider`。请改用 `theme.enabled`。

### 核心

从 Sidebar 组件中移除已弃用的选项 `minWidth`。请改用 `blockScrollingWidth`。

## 修复

### 用户界面

- 修复 twoslash 代码块的问题
- 对标题应用排版样式
- 支持主题标签的翻译

### OpenAPI

- 修复无法检测可空类型的问题

### 核心

- 标题标注：支持标题中的代码语法

### Create Fumadocs App

- 添加 `layout.config.tsx` 文件以共享布局选项
