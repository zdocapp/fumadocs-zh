## 介绍

Fumadocs v13 已发布。该版本旨在修复 CSS 污染问题并移除已弃用的 API。

## 新特性

### 更优的代码块

现支持在 `CodeBlock` 组件上保留由 Shiki 生成的原始背景。

```tsx
import { Pre, CodeBlock } from 'fumadocs-ui/components/codeblock';

<MDX
  components={{
    pre: ({ ref: _ref, ...props }) => (
      <CodeBlock keepBackground {...props}>
        <Pre>{props.children}</Pre>
      </CodeBlock>
    ),
  }}
/>;
```

### 提示框 (Callout)

提示框 (Callout) 现已成为默认的 MDX 组件，您无需导入即可在 MDX 文件中使用它，或手动将其添加到 MDX 组件中。

```mdx
<Callout type="warn">Hello World</Callout>
```

### 新的无样式目录 (Headless TOC)

目录 (Table of Contents, TOC) 的无样式组件现在拥有一个独立的滚动容器提供者。

```tsx
import * as Base from 'fumadocs-core/toc';

return (
  <Base.AnchorProvider>
    <Base.ScrollProvider>
      <Base.TOCItem />
      <Base.TOCItem />
    </Base.ScrollProvider>
  </Base.AnchorProvider>
);
```

锚点提供者可以放置在任何位置。

### 退出容器 (Opt-out of Container)

现支持禁用由 Fumadocs UI 添加的 Tailwind CSS 默认容器样式。

```js
import { createPreset } from 'fumadocs-ui/tailwind-plugin';

/** @type {import('tailwindcss').Config} */
export default {
  presets: [
    createPreset({
      modifyContainer: false,
    }),
  ],
};
```

### 告示语法 (Admonition Syntax)

在 Docusaurus 中，有一个 [Admonition 语法](https://docusaurus.io/docs/markdown-features/admonitions)。

对于从 Docusaurus 迁移的用户，您可以启用新的 remark 插件以支持告示语法。

请参阅 [Remark Admonition](/docs/headless/mdx/remark-admonition)。

## 重大变更

### 为颜色、动画和工具类添加前缀

此前，Fumadocs UI 的 Tailwind CSS 插件添加了颜色（包括 `primary`、`secondary`），这些与 Shadcn UI 及其他设计系统存在冲突。
现已为它们添加了 `fd-` 前缀，以便在文档中灵活地使用独立的设计系统。

若要在您的主应用中使用 Fumadocs UI 的颜色，请启用 `addGlobalColors` 选项。

```js
import { createPreset } from 'fumadocs-ui/tailwind-plugin';

/** @type {import('tailwindcss').Config} */
export default {
  presets: [
    createPreset({
      addGlobalColors: true,
    }),
  ],
};
```

这会在没有 `fd-` 前缀的情况下添加颜色。

或者你也可以直接使用 `fd-` 前缀引用它们，比如 `bg-fd-background`。

### Tailwind CSS 插件仅支持 ESM

由于 Tailwind CSS 支持 TypeScript 配置，将整个插件迁移到 ESM 是有意义的。

在你的配置中使用 ESM 语法。

```ts
import { createPreset } from 'fumadocs-ui/tailwind-plugin';

/** @type {import('tailwindcss').Config} */
export default {
  content: [
    './app/**/*.{ts,tsx}',
    // others
  ],
  presets: [createPreset()],
};
```

### 移除 `RollButton` 组件

引入 `RollButton` 是因为移动视口上没有“目录”功能。
现在用户可以使用 TOC 弹出框来切换标题，它不再适合 Fumadocs UI 的设计。

你可以复制 [`RollButton` 的最后实现](https://github.com/fuma-nama/fumadocs/blob/fumadocs-ui%4012.5.6/packages/ui/src/components/roll-button.tsx)。

### 更好的国际化支持

现在 `I18nProvider` 组件需要 `locale` 属性，而不是从路径名解析。
这修复了 I18n 中间件的一些错误。

我们还更改了 `translations` 的用法，以减少客户端加载的额外翻译。
你必须直接传递活动翻译。

`locales` 作为语言选择组件上的可用选项传递。

```tsx
import { RootProvider } from 'fumadocs-ui/provider';
import type { ReactNode } from 'react';
import { I18nProvider } from 'fumadocs-ui/i18n';

export default function Layout({
  params: { lang },
  children,
}: {
  params: { lang: string };
  children: ReactNode;
}) {
  return (
    <html lang={lang}>
      <body>
        <I18nProvider
          locale={lang}
          // options
          locales={[
            {
              name: 'English',
              locale: 'en',
            },
            {
              name: 'Chinese',
              locale: 'cn',
            },
          ]}
          // translations
          translations={
            {
              cn: {
                toc: '目錄',
              },
            }[lang]
          }
        >
          <RootProvider>{children}</RootProvider>
        </I18nProvider>
      </body>
    </html>
  );
}
```

### 代码块用法

之前的用法令人困惑，一些属性直接传递给 `pre`，而另一些则不是。

在 v13 中，将所有属性传递给 `CodeBlock` 组件。
这也包括类名，如有必要，你可以更改自定义样式。

```tsx
import { Pre, CodeBlock } from 'fumadocs-ui/components/codeblock';

<MDX
  components={{
    // HTML `ref` attribute conflicts with `forwardRef`
    pre: ({ ref: _ref, ...props }) => (
      <CodeBlock {...props}>
        <Pre>{props.children}</Pre>
      </CodeBlock>
    ),
  }}
/>;
```

### 移除已弃用的 API

- 移除已弃用的 `fumadocs-ui/components/api` 组件。
- 将 `secondary` 链接项替换为 `icon` 链接项。
- 将 Tabs 组件上的 `id` 属性重命名为 `groupId`。

## Bug 修复

### UI

- 修复了由 Radix UI 引起的空文件夹动画问题。
