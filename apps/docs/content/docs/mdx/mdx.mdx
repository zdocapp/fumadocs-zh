## 扩展 MDX 选项 [#extended]

Fumadocs MDX 会应用一些默认的 MDX 选项，以便开箱即用地支持**语法高亮**等功能。

为了允许覆盖默认设置，Fumadocs MDX 在 [`ProcessorOptions`](https://mdxjs.com/packages/mdx/#processoroptions) 之上支持**扩展 MDX 选项**。
以下是附加选项：

### Remark 插件

默认应用以下插件：

- [Remark Image](/docs/headless/mdx/remark-image) - 处理图片
- [Remark Heading](/docs/headless/mdx/headings) - 提取目录
- [Remark Structure](/docs/headless/mdx/structure) - 生成搜索索引
- Remark Exports - 导出上述 remark 插件生成的输出

添加其他 remark 插件：

```ts tab="Global Config"
import { defineConfig } from 'fumadocs-mdx/config';
import { myPlugin } from './remark-plugin';

export default defineConfig({
  mdxOptions: {
    remarkPlugins: [myPlugin],
    // You can also pass a function to control the order of remark plugins.
    remarkPlugins: (v) => [myPlugin, ...v],
  },
});
```

```ts tab="Collection Config"
import { defineCollections, getDefaultMDXOptions } from 'fumadocs-mdx/config';
import { myPlugin } from './remark-plugin';

export const blog = defineCollections({
  type: 'doc',
  mdxOptions: getDefaultMDXOptions({
    remarkPlugins: [myPlugin],
    // You can also pass a function to control the order of remark plugins.
    remarkPlugins: (v) => [myPlugin, ...v],
  }),
});
```

### Rehype 插件

默认应用以下插件：

- [Rehype Code](/docs/headless/mdx/rehype-code) - 语法高亮

与 remark 插件相同，您可以传递数组或函数来添加其他 rehype 插件。

```ts tab="Global Config"
import { defineConfig } from 'fumadocs-mdx/config';
import { myPlugin } from './rehype-plugin';

export default defineConfig({
  mdxOptions: {
    rehypePlugins: (v) => [myPlugin, ...v],
  },
});
```

```ts tab="Collection Config"
import { defineCollections, getDefaultMDXOptions } from 'fumadocs-mdx/config';
import { myPlugin } from './rehype-plugin';

export const blog = defineCollections({
  type: 'doc',
  mdxOptions: getDefaultMDXOptions({
    rehypePlugins: (v) => [myPlugin, ...v],
  }),
});
```

### 自定义内置插件

自定义内置插件的选项，例如：

```ts tab="Global Config"
import { defineConfig } from 'fumadocs-mdx/config';

export default defineConfig({
  mdxOptions: {
    rehypeCodeOptions: {
      // options
    },
    remarkImageOptions: {
      // options
    },
    remarkHeadingOptions: {
      // options
    },
  },
});
```

```ts tab="Collection Config"
import { defineCollections, getDefaultMDXOptions } from 'fumadocs-mdx/config';

export const blog = defineCollections({
  type: 'doc',
  mdxOptions: getDefaultMDXOptions({
    rehypeCodeOptions: {
      // options
    },
    remarkImageOptions: {
      // options
    },
    remarkHeadingOptions: {
      // options
    },
  }),
});
```

### 从 `vfile.data` 导出属性

某些 remark 插件将其输出存储在 `vfile.data`（编译时内存）中，这些数据无法从您的代码中访问。
Fumadocs MDX 应用了一个 remark 插件，将 `vfile.data` 属性转换为 ESM 导出，因此您可以在导入 MDX 文件时访问这些属性。

您可以定义要导出的附加属性。

```ts tab="Global Config"
import { defineConfig } from 'fumadocs-mdx/config';

export default defineConfig({
  mdxOptions: {
    valueToExport: ['dataName'],
  },
});
```

```ts tab="Collection Config"
import { defineCollections, getDefaultMDXOptions } from 'fumadocs-mdx/config';

export const blog = defineCollections({
  type: 'doc',
  mdxOptions: getDefaultMDXOptions({
    valueToExport: ['dataName'],
  }),
});
```

默认情况下，包含：

- `toc` 用于 Remark Heading 插件
- `structuredData` 用于 Remark Structure 插件
- `frontmatter` 用于 MDX 的 frontmatter（使用 `gray-matter`）
