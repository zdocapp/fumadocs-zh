title: 包含
description: 复用其他文件中的内容。
---

## 使用方法

### Markdown

要显示来自另一个 Markdown/MDX 文件的内容，请在 `<include>` 标签中指定相对于文件本身的路径。

```mdx title="page.mdx"
<include>./another.mdx</include>
```

<Callout>
  For Markdown files, you don't need to escape for MDX syntax but note that
  you'll need `rehypeRaw` for HTML comments & content.
</Callout>

### CodeBlock

对于其他类型的文件，它将变为代码块：

```mdx title="page.mdx"
<include>./script.ts</include>

<include lang="md" meta='title="lib.md"'>
  page.md
</include>
```

### `cwd`

从 cwd 而非 Markdown 文件解析相对路径：

```mdx
<include cwd lang="tsx" meta='title="lib.ts"'>
  ./script.ts
</include>
```

### Section

对于 Markdown 文件，您可以复制其中的一个部分：

```mdx title="a.mdx"
<section id="test">

## Hello World

This is included

</section>

This is not included.
```

```mdx title="b.mdx"
<include>a.mdx#test</include>
```
