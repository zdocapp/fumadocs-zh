## 介绍

Fumadocs MDX 是一个将内容转换为类型安全数据的工具，类似于内容集合（Content Collections）。

它不是一个完整的内容管理系统（CMS），而是一个内容编译器 + 验证器，您可以使用它来处理博客文章和其他内容。

### 定义集合

**集合**（Collection）指的是包含特定类型文件的集合。您可以在配置文件（`source.config.ts`）中定义集合。

Fumadocs MDX 将集合转换为类型安全的数据，可在您的应用程序中访问。可用的集合：

<Tabs items={["doc", "meta", 'docs']}>

    <Tab value='doc'>

将 Markdown 和 MDX 文件编译为 React 服务器组件，并提供**目录**等实用属性。

```ts title="source.config.ts"
import { defineCollections } from 'fumadocs-mdx/config';

export const test = defineCollections({
  type: 'doc',
  dir: 'content/docs',
});
```

    </Tab>

    <Tab value='meta'>

将 YAML/JSON 文件转换为数据数组。

```ts title="source.config.ts"
import { defineCollections } from 'fumadocs-mdx/config';

export const test = defineCollections({
  type: 'meta',
  dir: 'content/docs',
});
```

    </Tab>
    <Tab value='docs'>

`meta` 和 `doc` 集合的组合，这是 Fumadocs 所需的。

```ts title="source.config.ts"
import { defineDocs } from 'fumadocs-mdx/config';

export const docs = defineDocs({
  dir: 'content/docs',
  docs: {
    // `doc` 集合的选项
  },
  meta: {
    // `meta` 集合的选项
  },
});
```

    </Tab>

</Tabs>

例如，`doc` 集合将转换 `.md` 和 `.mdx` 文件：

<Files>
  <Folder name="folder" defaultOpen>
    <File name="ui.md" />
  </Folder>
  <File name="hello.md" />
  <File name="index.mdx" />
  <File
    name="meta.json"
    className="opacity-50 cursor-not-allowed"
    aria-disabled
  />
</Files>

### 访问集合

集合将被编译成 JavaScript 文件供您的应用程序访问，输出格式根据您使用的框架而异。

[开始使用](#quickstart)您的框架以了解更多信息。

## 常见问题

### 内置属性

这些属性默认从 MDX 文件中导出。

| Property         | Description                    |
| ---------------- | ------------------------------ |
| `frontmatter`    | Frontmatter                    |
| `toc`            | 目录                           |
| `structuredData` | 结构化数据，适用于实现搜索功能 |

### 自定义 Frontmatter

使用 [`schema`](/docs/mdx/collections#schema-1) 选项传递验证模式，以验证 frontmatter 并定义其输出属性。

### MDX 插件

Fumadocs MDX 使用 [MDX Compiler](https://mdxjs.com/packages/mdx) 将 MDX 文件编译为 JavaScript 文件。

您可以在 [全局配置](/docs/mdx/global#mdx-options) 或 [集合配置](/docs/mdx/collections#mdxoptions) 中自定义它。
