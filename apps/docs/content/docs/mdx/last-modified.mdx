## 使用方法

此功能默认未启用，您可以从配置文件中启用它。请注意，它仅支持 Git 作为版本控制系统。
请确保您的机器上已安装 Git，并且**仓库不是浅克隆的**，因为它依赖于您的本地 Git 历史记录。

```ts title="source.config.ts"
import { defineConfig } from 'fumadocs-mdx/config';

export default defineConfig({
  lastModifiedTime: 'git', // [!code highlight]
});
```

### 访问属性

完成此操作后，将为每个文档导出一个 `lastModified` 数字。您可以将其转换为 JavaScript Date 对象。

```ts
import { source } from '@/lib/source';

const page = source.getPage(['...']);

console.log(new Date(page.data.lastModified));
// or with async mode:
const { lastModified } = await page.data.load();
console.log(new Date(lastModified));
```
