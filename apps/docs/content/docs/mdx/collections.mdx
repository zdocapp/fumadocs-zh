## 定义集合

定义一个集合来解析特定的文件集。

```ts
import { defineCollections } from 'fumadocs-mdx/config';
import { z } from 'zod';

export const blog = defineCollections({
  type: 'doc',
  dir: './content/blog',
  schema: z.object({
    // schema
  }),
  // other options
});
```

### `type`

集合的接受类型。

```ts
import { defineCollections } from 'fumadocs-mdx/config';

// only scan for json/yaml files
export const metaFiles = defineCollections({
  type: 'meta',
  // options
});
```

- `type: meta`

  接受 JSON/YAML 文件，可用选项：

  <AutoTypeTable path="./content/docs/mdx/props.ts" name="MetaCollection" />

- `type: doc`

  Markdown/MDX 文档，可用选项：

  <AutoTypeTable path="./content/docs/mdx/props.ts" name="DocCollection" />

### `dir`

扫描输入文件的目录。

### `schema`

用于验证文件数据的模式（`doc` 类型的前言数据，`meta` 类型的内容）。

```ts
import { defineCollections } from 'fumadocs-mdx/config';
import { z } from 'zod';

export const blog = defineCollections({
  type: 'doc',
  dir: './content/blog',
  schema: z.object({
    name: z.string(),
  }),
});
```

> 支持 [Standard Schema](https://standardschema.dev) 兼容库，包括 Zod。

请注意，验证在构建时进行，因此输出必须是可序列化的。
你也可以传递一个接收转换上下文的函数。

```ts
import { defineCollections } from 'fumadocs-mdx/config';
import { z } from 'zod';

export const blog = defineCollections({
  type: 'doc',
  dir: './content/blog',
  schema: (ctx) => {
    return z.object({
      name: z.string(),
      testPath: z.string().default(
        // original file path
        ctx.path,
      ),
    });
  },
});
```

### `mdxOptions`

在集合级别自定义 MDX 选项。

```ts title="source.config.ts"
import { defineCollections, getDefaultMDXOptions } from 'fumadocs-mdx/config';

export const blog = defineCollections({
  type: 'doc',
  mdxOptions: {
    // mdx options
  },
});
```

根据设计，这将移除全局配置和 Fumadocs MDX 应用的所有默认设置。
你可以完全控制 MDX 选项。

你可以使用 `getDefaultMDXOptions` 来应用默认配置，它接受[扩展的 MDX 选项](/docs/mdx/mdx#extended)。

```ts title="source.config.ts"
import { defineCollections, getDefaultMDXOptions } from 'fumadocs-mdx/config';

export const blog = defineCollections({
  type: 'doc',
  mdxOptions: getDefaultMDXOptions({
    // extended mdx options
  }),
});
```

> 此 API 仅在 `doc` 类型中可用。

## 定义文档

为 Fumadocs 定义一个集合。

```ts
import { defineDocs } from 'fumadocs-mdx/config';

export const docs = defineDocs({
  dir: '/my/content/dir',
  docs: {
    // optional, options of `doc` collection
  },
  meta: {
    // optional, options of `meta` collection
  },
});
```

### `dir`

不应按集合自定义，而应从 `defineDocs` 自定义 `dir`：

```ts
import { defineDocs } from 'fumadocs-mdx/config';

export const docs = defineDocs({
  dir: 'my/content/dir',
});
```

### `schema`

您可以扩展 `docs` 和 `meta` 的默认 Zod schema。

```ts
import { frontmatterSchema, metaSchema, defineDocs } from 'fumadocs-mdx/config';
import { z } from 'zod';

export const docs = defineDocs({
  docs: {
    schema: frontmatterSchema.extend({
      index: z.boolean().default(false),
    }),
  },
  meta: {
    schema: metaSchema.extend({
      // other props
    }),
  },
});
```
