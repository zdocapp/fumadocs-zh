---

[Shiki](https://shiki.style) 的封装，内置语法高亮器。

## 使用方法

添加 rehype 插件。

```ts title="MDX Compiler"
import { compile } from '@mdx-js/mdx';
import { rehypeCode } from 'fumadocs-core/mdx-plugins';

await compile('...', {
  rehypePlugins: [rehypeCode],
});
```

> 该插件默认包含在 Fumadocs MDX 中。

### 输出

包裹在 `<pre />` 元素中的代码块。

```html
<pre>
<code>...</code>
</pre>
```

### 元数据

它会解析 `title` 元字符串，并将其作为属性添加到 `pre` 元素中。

````mdx
```js title="Title"
console.log('Hello');
```
````

您可以使用 `filterMetaString` 选项在处理前过滤元字符串。

### 内联代码

`console.log("hello world"){:js}` 有效。

参见 https://shiki.style/packages/rehype#inline-code。

### 图标

根据代码块的语言添加图标。
它会输出 HTML，您可能需要使用 React 的 `dangerouslySetInnerHTML` 来渲染。

```jsx
<pre icon="<svg />">...</pre>
```

使用 `icon` 选项禁用或自定义图标。
