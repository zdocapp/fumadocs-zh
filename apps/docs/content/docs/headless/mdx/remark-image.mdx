---
title: 图像尺寸标注
description: 为图像添加尺寸属性。
---

该插件为您的图片元素添加 `width` 和 `height` 属性，这是 Next.js 和其他一些框架进行图片优化所必需的。

## 使用方法

将其添加到您的 Remark 插件中。

```ts title="MDX Compiler"
import { compile } from '@mdx-js/mdx';
import { remarkImage } from 'fumadocs-core/mdx-plugins';

await compile('...', {
  remarkPlugins: [remarkImage],
});
```

> 该插件默认包含在 Fumadocs MDX 中。

支持：

- 本地图片
- 外部 URL
- Next.js 静态导入

### 工作原理

对于 Next.js，它使用**静态导入**来导入本地图片，这支持 Next.js Image 的 `placeholder` 选项。
Next.js 可以使用其内置的图片加载器处理图片导入。

否则，它将使用文件系统或 HTTP 请求下载图片并获取其尺寸。

### 示例：使用导入

```mdx
![Hello](/hello.png)
![Test](https://example.com/image.png)
```

生成：

```mdx
import HelloImage from './public/hello.png';

<img alt="Hello" src={HelloImage} />
<img
  alt="Test"
  src="https://example.com/image.png"
  width="1980"
  height="1080"
/>
```

其中 `./public/hello.png` 指向公共目录中的图片。

### 示例：不使用导入

对于 Next.js，您可以禁用本地图片的静态导入。

```ts
import { remarkImage } from 'fumadocs-core/mdx-plugins';

export default {
  remarkPlugins: [[remarkImage, { useImport: false }]],
};
```

```mdx
![Hello](/hello.png)
![Test](https://example.com/image.png)
```

生成：

```mdx
<img alt="Hello" src="/hello.png" width="1980" height="1080" />
<img
  alt="Test"
  src="https://example.com/image.png"
  width="1980"
  height="1080"
/>
```

### 示例：相对路径

当启用 `useImport` 时，您可以使用相对路径引用本地图片。

```mdx
![Hello](./hello.png)
```

请注意，在禁用 `useImport` 的情况下使用它**不起作用**。
除非您在代码中导入了图片，否则 Next.js 不会将图片添加到公共资源中。
对于公共目录中的图片，您可以直接引用它们而无需使用相对路径。

### 示例：公共目录

自定义公共目录的路径

```ts
import { remarkImage } from 'fumadocs-core/mdx-plugins';
import path from 'node:path';

export default {
  remarkPlugins: [
    remarkImage,
    {
      publicDir: path.join(process.cwd(), 'dir'),
    },
  ],
};
```

您也可以传递一个 URL。

```ts
import { remarkImage } from 'fumadocs-core/mdx-plugins';

export default {
  remarkPlugins: [
    remarkImage,
    {
      publicDir: 'https://my-cdn.com/images',
    },
  ],
};
```
