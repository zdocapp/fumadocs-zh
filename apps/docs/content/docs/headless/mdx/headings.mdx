## Remark Heading

为标题应用 id。

```ts title="MDX Compiler"
import { compile } from '@mdx-js/mdx';
import { remarkHeading } from 'fumadocs-core/mdx-plugins';

await compile('...', {
  remarkPlugins: [remarkHeading],
});
```

> 该插件默认包含在 Fumadocs MDX 中。

### 提取目录

默认情况下，它会提取文档的标题（目录）到 `vfile.data.toc`。
您可以通过以下方式禁用它：

```ts
import { remarkHeading } from 'fumadocs-core/mdx-plugins';

export default {
  remarkPlugins: [[remarkHeading, { generateToc: false }]],
};
```

### 自定义 ID [#custom-heading-id]

您可以使用 `[#slug]` 自定义标题 id。

```md
# heading [#slug]
```

## Rehype TOC

导出目录（一个 `TOCItemType` 数组），它允许 JSX 节点，这是 Remark 插件无法实现的。

> [!NOTE]
> 它需要 MDX.js。

### 用法

```ts
import { rehypeToc } from 'fumadocs-core/mdx-plugins';

export default {
  rehypePlugins: [rehypeToc],
};
```

### 输出

对于 Markdown 文档：

```md
## Hello `code`
```

将创建一个导出：

```jsx
export const toc = [
  {
    title: (
      <>
        Hello <code>code</code>
      </>
    ),
    depth: 2,
    url: '#hello-code',
  },
];
```
