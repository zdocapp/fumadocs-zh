## 使用方法

将其作为 remark 插件添加。

```ts title="MDX Compiler"
import { compile } from '@mdx-js/mdx';
import { remarkStructure } from 'fumadocs-core/mdx-plugins';

const vfile = await compile('...', {
  remarkPlugins: [remarkStructure],
});
```

> 该插件默认包含在 Fumadocs MDX 中。

提取的信息可在 `vfile.data.structuredData` 中找到，您可以编写自己的插件将其转换为 MDX 导出。

### 输出

包含标题和内容的列表。段落将被提取到 `contents` 数组中，每个条目包含一个 `heading` 属性，表示段落的标题。

<Callout title="注意">一个标题可以包含多个段落。</Callout>

#### 标题

| 属性      |                         |
| --------- | ----------------------- |
| `id`      | 标题的唯一标识符或 slug |
| `content` | 文本内容                |

#### 内容

| 属性      |                      |
| --------- | -------------------- |
| `heading` | 段落的标题（可为空） |
| `content` | 文本内容             |

## 作为函数使用

接受 MDX/markdown 内容并返回结构化数据。

```ts
import { structure } from 'fumadocs-core/mdx-plugins';

structure(page.body.raw);
```

<Callout title="Tip" className="mt-4">
If you have custom remark plugins enabled, such as
`remark-math`, you have to pass these plugins to the function. This avoids unreadable content on paragraphs.

```ts
import { structure } from 'fumadocs-core/mdx-plugins';
import remarkMath from 'remark-math';

structure(page.body.raw, [remarkMath]);
```

</Callout>

### 参数

| 参数            |                   |
| --------------- | ----------------- |
| `content`       | MDX/markdown 内容 |
| `remarkPlugins` | remark 插件列表   |
| `options`       | 自定义选项        |
