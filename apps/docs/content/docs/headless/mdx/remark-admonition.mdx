title: Remark 提示框
description: 在 Fumadocs 中使用提示框
---

在 Docusaurus 中，有一个 [Admonition 语法](https://docusaurus.io/docs/markdown-features/admonitions)。

对于从 Docusaurus 迁移的用户，您可以启用此 remark 插件以支持 Admonition 语法。

## 使用方法

```ts title="source.config.ts" tab="Fumadocs MDX"
import { remarkAdmonition } from 'fumadocs-core/mdx-plugins';
import { defineConfig } from 'fumadocs-mdx/config';

export default defineConfig({
  mdxOptions: {
    remarkPlugins: [remarkAdmonition],
  },
});
```

```ts tab="MDX Compiler"
import { compile } from '@mdx-js/mdx';
import { remarkAdmonition } from 'fumadocs-core/mdx-plugins';

await compile('...', {
  remarkPlugins: [remarkAdmonition],
});
```

### 输入

```md
:::warning
Hello World
:::
```

### 输出

```mdx
<Callout type='warn'>

Hello World

</Callout>
```

### 使用时机

我们强烈建议使用 MDX 的 JSX 语法替代。
它更加灵活，一些编辑器在 MDX 文件中支持智能感知。

```mdx
<Callout type='warn'>

Hello World

</Callout>
```
