<Callout title='Before reading'>

    This guide only applies for content sources that uses `loader()` API, such as Fumadocs MDX.

</Callout>

## 概述

虽然您的 React 框架处理路由，但 Fumadocs 使用 [`loader()`](/docs/headless/source-api) 从您的内容目录生成**页面 slugs** 和**侧边栏项**（页面树）。

您可以定义类似于基于文件系统的路由的文件夹和页面。

<Files>
  <Folder name="content/docs (content directory)" defaultOpen>
    <File name="index.mdx" />
    <File name="getting-started.mdx" />
  </Folder>
</Files>

## 文件

一个 [MDX](https://mdxjs.com) 或 Markdown 文件，您可以自定义其 frontmatter。

```mdx
---
title: My Page
description: Best document ever
icon: HomeIcon
---

## Learn More
```

| 名称          | 描述                          |
| ------------- | ----------------------------- |
| `title`       | 页面标题                      |
| `description` | 页面描述                      |
| `icon`        | 图标名称，参见 [图标](#icons) |

<Callout title='Fumadocs MDX'>

    You can use the [`schema`](/docs/mdx/collections#schema-1) option to add frontmatter properties.

</Callout>

### Slugs

页面的 slugs 是根据其文件路径生成的。

| 路径（相对于内容文件夹） | slugs             |
| ------------------------ | ----------------- |
| `./dir/page.mdx`         | `['dir', 'page']` |
| `./dir/index.mdx`        | `['dir']`         |

## 文件夹

组织多个页面，您可以创建一个 [元文件](#meta) 来自定义文件夹。

### 文件夹组

默认情况下，将文件放入文件夹会更改其 slugs。
您可以将文件夹名称用括号括起来，以避免影响子文件的 slugs。

| 路径（相对于内容文件夹） | 路径段     |
| ------------------------ | ---------- |
| `./(分组名称)/page.mdx`  | `['page']` |

### 根文件夹

将文件夹标记为根文件夹，只有已打开的根文件夹中的项目才会显示。

```json title="meta.json"
{
  "title": "Name of Folder",
  "description": "The description of root folder (optional)",
  "root": true
}
```

例如，当您打开根文件夹 `framework` 时，其他文件夹（例如 `headless`）不会显示在侧边栏和其他导航元素上。

<Files>
  <Folder name="framework" defaultOpen>
    <File name="index.mdx" />
    <File
      name="current-page.mdx"
      className="!text-fd-primary !bg-fd-primary/10"
    />
    <File name="other-pages.mdx" />
  </Folder>
  <Folder name="headless (hidden)" className="opacity-50" disabled defaultOpen>
    <File name="my-page.mdx" />
  </Folder>
</Files>

<Callout title='Fumadocs UI'>

Fumadocs UI renders root folders as [Sidebar Tabs](/docs/ui/navigation/sidebar#sidebar-tabs), which allows user to switch between them.

</Callout>

## 元数据

通过在文件夹中创建 `meta.json` 文件来自定义文件夹。

```json title="meta.json"
{
  "title": "Display Name",
  "icon": "MyIcon",
  "pages": ["index", "getting-started"],
  "defaultOpen": true
}
```

| 名称          | 描述                          |
| ------------- | ----------------------------- |
| `title`       | 显示名称                      |
| `icon`        | 图标名称，参见 [图标](#icons) |
| `pages`       | 文件夹项目（见下文）          |
| `defaultOpen` | 默认打开文件夹                |

### 页面

文件夹项目默认按字母顺序排序，您可以使用 `pages` 添加或控制项目的顺序。

```json title="meta.json"
{
  "pages": ["index", "getting-started"]
}
```

> [!NOTE]
> 当指定时，除非项目列在 `pages` 中，否则不会包含它们。

- **路径**：指向页面或文件夹的路径，例如 `./nested/page`。
- **分隔符** (`---标签---`)：两个部分之间的分隔符，使用 `---[图标]标签---` 来包含图标。
- **链接** (`[文本](url)`)：插入链接，使用 `[图标][文本](url)` 来包含图标。

特殊项目：

- **Rest** (`...`): 包含剩余页面（按字母顺序排序）。
- **Reversed Rest** (`z...a`): 反向的 **Rest** 项，
- **Extract** (`...folder`): 从文件夹中提取项目。

```json title="meta.json"
{
  "pages": [
    "components",
    "---My Separator---",
    "...folder",
    "...",
    "[Vercel](https://vercel.com)",
    "[Triangle][Vercel](https://vercel.com)"
  ]
}
```

## 图标

由于 Fumadocs 不包含图标库，您需要在运行时将图标名称转换为 JSX 元素，并将其渲染为组件。

您可以为 `loader()` 添加一个 [`icon` 处理程序](/docs/headless/source-api#icons)。

## 国际化路由

您可以为国际化路由定义不同的样式。

```ts title="lib/i18n.ts"
import type { I18nConfig } from 'fumadocs-core/i18n';

export const i18n: I18nConfig = {
  // default
  parser: 'dot',
  // or
  parser: 'dir',
};
```

<Tabs items={['点标记', '目录结构']}>

  <Tab>

    通过在文件名后附加 `.{locale}` 来为不同语言添加 Markdown/元数据文件，例如：

    <Files>
      <Folder name="content/docs" defaultOpen>
        <File name="meta.json" />
        <File name="meta.cn.json" />
        <File name="get-started.mdx" />
        <File name="get-started.cn.mdx" />
      </Folder>
    </Files>

    对于默认语言环境，语言代码是可选的。

  </Tab>

    <Files>
      <Folder name="content/docs" defaultOpen>
        <Folder name='en' defaultOpen>
          <File name="meta.json" />
          <File name="get-started.mdx" />
        </Folder>

        <Folder name='cn' defaultOpen>
          <File name="meta.json" />
          <File name="get-started.mdx" />
        </Folder>
      </Folder>
    </Files>

  </Tab>
