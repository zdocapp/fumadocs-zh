## 使用方法

`loader()` 为 Fumadocs 提供了一个接口，用于与基于文件系统的内容源集成。

### 功能是什么？

- 基于文件系统生成页面树。
- 为每个页面分配 URL 和 slugs。
- 输出有用的工具来与内容交互。

它不依赖真实的文件系统（零 `node:fs` 使用），也允许使用虚拟存储。

你可以将其与内置的内容源（如 Fumadocs MDX）一起使用。

```ts
import { loader } from 'fumadocs-core/source';
import { docs } from '@/.source';

export const source = loader({
  source: docs.toFumadocsSource(),
});
```

### URL

你可以覆盖基础 URL，或指定一个函数来为每个页面生成 URL。

```ts
import { loader } from 'fumadocs-core/source';

loader({
  baseUrl: '/docs',
  // or you can customise it with function
  url(slugs, locale) {
    if (locale) return '/' + [locale, 'docs', ...slugs].join('/');
    return '/' + ['docs', ...slugs].join('/');
  },
});
```

### 图标

加载由页面和元文件指定的 [图标](/docs/headless/page-conventions#icons) 属性。

```ts
import { loader } from 'fumadocs-core/source';
import { icons } from 'lucide-react';
import { createElement } from 'react';

loader({
  icon(icon) {
    if (!icon) {
      // You may set a default icon
      return;
    }

    if (icon in icons) return createElement(icons[icon as keyof typeof icons]);
  },
});
```

### 国际化 (I18n)

将 `i18n` 配置传递给 loader。

```ts title="lib/source.ts"
import { i18n } from '@/lib/i18n';
import { loader } from 'fumadocs-core/source';

export const source = loader({
  i18n, // [!code highlight]
});
```

启用 i18n 后，loader 将为每个语言环境生成一个页面树。

如果页面缺少翻译，它将回退到 [`fallbackLanguage`](/docs/headless/internationalization#fallback-language)。

## 输出

loader 输出一个源对象。

### 获取页面

通过 slugs 获取页面。

```ts
import { source } from '@/lib/source';

source.getPage(['slug', 'of', 'page']);

// with i18n
source.getPage(['slug', 'of', 'page'], 'locale');
```

### 获取页面列表

获取可用于特定语言环境的页面列表。

```ts
import { source } from '@/lib/source';

// from default locale
source.getPages();

// for a specific locale
source.getPages('locale');
```

### 页面树

```ts
import { source } from '@/lib/source';

// without i18n
source.pageTree;

// with i18n
source.pageTree['locale'];
```

### 从节点获取

页面树节点包含对其原始文件路径的引用。
你可以从树节点中找到它们的原始页面或元文件。

```ts
import { source } from '@/lib/source';

source.getNodePage(pageNode);
source.getNodeMeta(folderNode);
```

### 参数

一个用于为 Next.js `generateStaticParams` 生成输出的函数。
生成的参数名称将为 `slug: string[]` 和 `lang: string`（仅限 i18n）。

```ts title="app/[[...slug]]/page.tsx"
import { source } from '@/lib/source';

export function generateStaticParams() {
  return source.generateParams();
}
```

### 语言条目

获取可用语言及其页面。

```ts
import { source } from '@/lib/source';

// language -> pages
const entries = source.getLanguages();
```

## 深入探讨

如前所述，Source API 不依赖真实的文件系统。
在此过程中，您的输入源文件将被解析并形成一个虚拟存储，以避免不同操作系统之间的不一致行为。

### 转换器

为了在处理前执行虚拟文件系统操作，您可以添加一个转换器。

```ts
import { loader } from 'fumadocs-core/source';

loader({
  transformers: [
    ({ storage }) => {
      storage.makeDir();
    },
  ],
});
```

### 页面树

页面树是从您的文件系统生成的，一些不必要的信息（例如未使用的前言属性）将被过滤。

您可以使用 `pageTree` 选项来自定义它，例如为节点附加自定义属性，或自定义页面的显示名称。

```tsx
import React from 'react';
import { loader } from 'fumadocs-core/source';

loader({
  pageTree: {
    transformers: [
      {
        file(node, file) {
          // you can access its file information
          if (file) console.log(file, this.storage.read(file));

          // JSX nodes are allowed
          node.name = <>Some JSX Nodes here</>;

          return node;
        },
      },
    ],
  },
});
```

### 自定义源

要接入您自己的内容源，请创建一个 `Source` 对象。

它包括一个 `files` 属性，这是一个虚拟文件数组。
每个虚拟文件必须包含其文件路径和相应的数据。
您可以查看类型定义以获取更多信息。

由于 Source API 不依赖文件系统，文件路径不能是绝对或相对的（例如，不允许使用 `./file.mdx` 和 `D://content/file.mdx`）。
相反，请传递像 `file.mdx` 和 `content/file.mdx` 这样的文件路径。

```ts
import { Source } from 'fumadocs-core/source';

export function createMySource(): Source<{
  metaData: { title: string; pages: string[] }; // Your custom type
  pageData: { title: string; description: string }; // Your custom type
}> {
  return {
    files: [],
  };
}
```
