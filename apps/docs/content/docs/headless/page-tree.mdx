页面树是一种树状结构，用于描述所有导航链接，以及其他项目如分隔符和文件夹。

它将被发送到客户端，并在包括侧边栏和面包屑在内的导航元素中被引用。
因此，您不应在页面树中存储任何敏感或大型数据。

<Callout title="Note">

By design, page tree only contains necessary information of all pages and folders.

Unserializable data such as functions can't be passed to page tree.

</Callout>

## 约定

页面树的类型定义，适用于希望硬编码/生成它的人员。
您也可以从 Fumadocs 导入该类型。

```ts
import type { PageTree } from 'fumadocs-core/server';

const tree: PageTree.Root = {
  // props
};
```

某些节点包含一个 `$ref` 属性，它们是内部使用的，在硬编码时不使用。
