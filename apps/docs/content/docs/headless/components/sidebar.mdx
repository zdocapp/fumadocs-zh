一个侧边栏组件，可处理设备尺寸调整并自动移除滚动条。

## 使用方法

```tsx
import * as Base from 'fumadocs-core/sidebar';

return (
  <Base.SidebarProvider>
    <Base.SidebarTrigger />
    <Base.SidebarList />
  </Base.SidebarProvider>
);
```
