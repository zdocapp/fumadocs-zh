一个包装您 React 框架（例如 `next/link`）的 Link 组件，并自动处理文档中的外部链接。~
当检测到外部 URL 时，它会使用 `<a>` 标签而不是 Link 组件。

`rel` 属性会自动生成。

## 使用方法

用法与使用 `<a>` 标签相同。

```mdx
import Link from 'fumadocs-core/link';

<Link href="/docs/components">Click Me</Link>
```

### 外部链接

您可以通过传递 `external` 属性来强制将 URL 视为外部链接。

### 动态 href

您可以通过导入 `dynamic-link` 来启用动态 href。

```mdx
import { DynamicLink } from 'fumadocs-core/dynamic-link';

<DynamicLink href="/[lang]/components">Click Me</DynamicLink>
```
