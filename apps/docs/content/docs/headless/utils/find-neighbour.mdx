---
title: 查找相邻页面
description: 从页面树中查找页面的相邻页面
---

从页面树中查找页面的相邻页面，它返回给定页面的下一页和上一页。这对于实现页脚非常有用。

## 使用方法

它需要一个页面树和页面的URL。

```ts
import { findNeighbour } from 'fumadocs-core/server';
import { pageTree } from '@/lib/source';

const neighbours = findNeighbour(pageTree, '/url/to/page');
```

| 参数 | 类型       | 描述      |
| ---- | ---------- | --------- |
| tree | `PageTree` | 页面树    |
| url  | `string`   | 页面的URL |
