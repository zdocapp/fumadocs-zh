从 markdown/mdx 内容解析目录。

> [您可以直接使用 remark 插件](/docs/headless/mdx/headings)

## 使用方法

注意：如果您正在使用 CMS，则应使用 CMS 提供的 API。

```ts
import { getTableOfContents } from 'fumadocs-core/server';

const toc = getTableOfContents('## markdown content');
```

### 输出

返回一个 [`TOCItemType`](/docs/headless/mdx/headings#output) 数组。
