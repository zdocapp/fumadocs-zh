## 介绍

Mixedbread 集成使用向量搜索为您的文档提供语义搜索功能。它将您的文档内容索引到向量存储中，使用户能够使用自然语言查询进行搜索，并根据含义而非仅关键词匹配找到相关内容。

## 设置

### 获取 API 密钥

1. 在 [Mixedbread](https://platform.mixedbread.com) 注册账号
2. 前往 [API Keys](https://platform.mixedbread.com/platform?next=api-keys)
3. 创建新的 API 密钥并将其存储在环境变量中

### 创建向量存储

要同步您的文档，您需要创建一个向量存储：

1. 在 Mixedbread 仪表板中前往 [Vector Stores](https://platform.mixedbread.com/platform?next=vector-stores)
2. 为您的文档创建新的向量存储
3. 复制向量存储 ID

### 同步文档

使用 [Mixedbread CLI](https://www.mixedbread.com/cli) 同步您的文档：

安装 CLI：

```package-install
@mixedbread/cli -D
```

配置身份验证并同步您的文档：

```bash
# Configure authentication
mxbai config keys add YOUR_API_KEY

# Sync your documentation
mxbai vs sync YOUR_VECTOR_STORE_ID "./content/docs"
```

CLI 将自动检测文档中的更改并相应更新向量存储。

### 工作流程

您可以通过在 `package.json` 中添加同步脚本来自动同步文档：

```json
{
  "scripts": {
    "build": "... && mxbai vs sync YOUR_VECTOR_STORE_ID './content/docs' --ci"
  }
}
```

## 选项

### 标签筛选

要按标签筛选搜索结果，请在文档元数据中添加标签字段：

```md
---
title: Mixedbread
description: Integrate Mixedbread Search with Fumadocs
url: /docs/headless/search/mixedbread
// [!code ++]
tag: docs
---
```

并更新您的搜索客户端：

- **Fumadocs UI**: 在搜索界面上启用[标签筛选器](/docs/ui/search/orama#tag-filter)。
- **搜索客户端**: 您可以像这样添加标签筛选器：

  ```ts
  import { useDocsSearch } from 'fumadocs-core/search/client';

  const { search, setSearch, query } = useDocsSearch({
    tag: '<your tag value>',
    // ...
  });
  ```

这使您能够将搜索范围限定到文档的特定部分。
