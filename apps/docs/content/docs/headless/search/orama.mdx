Fumadocs 支持使用 Orama 进行文档搜索，这是默认且推荐的选项，因为它可以自托管且完全免费。

### 从搜索索引创建

从搜索索引创建服务器，每个索引都需要一个 `structuredData` 字段。

通常，这由您的内容源（例如 Fumadocs MDX）提供。您也可以使用 [Remark Structure](/docs/headless/mdx/structure) 插件从 Markdown/MDX 文档中提取。

```ts tab="Next.js" title="app/api/search/route.ts"
import { source } from '@/lib/source';
import { createSearchAPI } from 'fumadocs-core/search/server';

export const { GET } = createSearchAPI('advanced', {
  language: 'english',
  indexes: source.getPages().map((page) => ({
    title: page.data.title,
    description: page.data.description,
    url: page.url,
    id: page.url,
    structuredData: page.data.structuredData,
  })),
});
```

```ts tab="React Router" title="app/docs/search.ts"
import type { Route } from './+types/search';
import { createSearchAPI } from 'fumadocs-core/search/server';
import { source } from '@/lib/source';

const server = createSearchAPI('advanced', {
  language: 'english',
  indexes: source.getPages().map((page) => ({
    title: page.data.title,
    description: page.data.description,
    url: page.url,
    id: page.url,
    structuredData: page.data.structuredData,
  })),
});

export async function loader({ request }: Route.LoaderArgs) {
  return server.GET(request);
}
```

```ts tab="Tanstack Start" title="src/routes/api/search.ts"
import { createServerFileRoute } from '@tanstack/react-start/server';
import { source } from '@/lib/source';
import { createSearchAPI } from 'fumadocs-core/search/server';

const server = createSearchAPI('advanced', {
  language: 'english',
  indexes: source.getPages().map((page) => ({
    title: page.data.title,
    description: page.data.description,
    url: page.url,
    id: page.url,
    structuredData: page.data.structuredData,
  })),
});

export const ServerRoute = createServerFileRoute('/api/search').methods({
  GET: async ({ request }) => server.GET(request),
});
```

### 搜索文档

您可以使用以下方式搜索文档：

- **Fumadocs UI**：开箱即用支持，详见 [搜索界面](/docs/ui/search/orama)。
- **搜索客户端**：

```ts twoslash
import { useDocsSearch } from 'fumadocs-core/search/client';

const client = useDocsSearch({
  type: 'fetch',
});
```

## 配置

### 标签筛选

支持按标签筛选结果，这对于实现类似本文档的多文档功能非常有用。

```ts
import { source } from '@/lib/source';
import { createFromSource } from 'fumadocs-core/search/server';

const server = createFromSource(source, {
  buildIndex(page) {
    return {
      title: page.data.title,
      description: page.data.description,
      url: page.url,
      id: page.url,
      structuredData: page.data.structuredData,
      // use your desired value, like page.slugs[0] [!code ++]
      tag: '<value>',
    };
  },
});
```

并更新您的搜索客户端：

- **Fumadocs UI**：在搜索界面上配置 [标签筛选](/docs/ui/search/orama#tag-filter)。
- **搜索客户端**：向钩子传递一个标签。

```ts
import { useDocsSearch } from 'fumadocs-core/search/client';

const client = useDocsSearch({
  type: 'fetch',
  tag: '<value>', // [!code ++]
});
```

### 静态模式 [#static-export]

为了支持无服务器使用，请使用搜索服务器中的 `staticGET`。例如：

```ts tab="Next.js" title="app/api/search/route.ts"
import { source } from '@/lib/source';
import { createFromSource } from 'fumadocs-core/search/server';

// it should be cached forever
export const revalidate = false;

// [!code highlight]
export const { staticGET: GET } = createFromSource(source);
```

```ts tab="React Router" title="app/docs/search.ts"
import type { Route } from './+types/search';

export async function loader({ request }: Route.LoaderArgs) {
  // [!code highlight]
  return server.staticGET(request);
}
```

```ts tab="Tanstack Start" title="src/routes/api/search.ts"
import { createServerFileRoute } from '@tanstack/react-start/server';

export const ServerRoute = createServerFileRoute('/api/search').methods({
  // [!code highlight]
  GET: async ({ request }) => server.staticGET(request),
});
```

> `staticGET` 在 `createSearchAPI` 中也可用。

并更新您的搜索客户端：

- **Fumadocs UI**: 在搜索界面使用[静态客户端](/docs/ui/search/orama#static)。

- **搜索客户端**: 使用 `static` 替代 `fetch`。

  ```ts
  import { useDocsSearch } from 'fumadocs-core/search/client';

  const client = useDocsSearch({
    type: 'static',
  });
  ```

<Callout type='warn' title="Be Careful">

    Static Search requires clients to download the exported search indexes.
    For large docs sites, it can be expensive.

    You should use cloud solutions like Orama Cloud or Algolia for these cases.

## 国际化

请确保您的语言在 Orama [支持的语言](https://docs.orama.com/docs/orama-js/supported-languages)列表中。

```ts title="app/api/search/route.ts" tab="From Source"
import { source } from '@/lib/source';
import { createFromSource } from 'fumadocs-core/search/server';

const server = createFromSource(source, {
  localeMap: {
    // [locale]: Orama options [!code ++:2]
    ru: { language: 'russian' },
    en: { language: 'english' },
  },
});
```

```ts tab="From Search Indexes"
import { source } from '@/lib/source';
import { createI18nSearchAPI } from 'fumadocs-core/search/server';
import { i18n } from '@/lib/i18n';

const server = createI18nSearchAPI('advanced', {
  i18n, // [!code ++]
  indexes: source.getLanguages().flatMap(({ language, pages }) =>
    pages.map((page) => ({
      title: page.data.title,
      description: page.data.description,
      structuredData: page.data.structuredData,
      id: page.url,
      url: page.url,
      locale: language === 'ru' ? 'russian' : 'english', // [!code ++]
    })),
  ),
});
```

对于**静态模式**，您需要从客户端进行配置：

```tsx title="components/search.tsx"
import { useDocsSearch } from 'fumadocs-core/search/client';
import { create } from '@orama/orama';

function initOrama(locale?: string) {
  return create({
    schema: { _: 'string' },
    // [!code ++]
    language: locale === 'ru' ? 'russian' : 'english',
  });
}

function Search() {
  const client = useDocsSearch({
    type: 'static',
    initOrama,
  });

  // ...
}
```

### 特殊语言

中文和日语需要额外配置：

```npm
@orama/tokenizers
```

<include cwd meta='title="app/api/search/route.ts" tab="createFromSource"'>
  ../../examples/i18n/app/api/search/route.ts
</include>

```tsx tab="Static mode" title="components/search.tsx"
import { useDocsSearch } from 'fumadocs-core/search/client';
import { createTokenizer } from '@orama/tokenizers/mandarin';
import { create } from '@orama/orama';

// [!code focus:8]
function initOrama(locale?: string) {
  return create({
    schema: { _: 'string' },
    components: {
      tokenizer: locale === 'cn' ? createTokenizer() : undefined,
    },
  });
}

function Search() {
  const client = useDocsSearch({
    type: 'static',
    initOrama,
  });
  // ...
}
```

并更新您的搜索客户端：

- **Fumadocs UI**: 无需更改，当您正确配置 i18n 时，Fumadocs UI 会自动处理此问题。
- **搜索客户端**:
  在搜索客户端中添加 `locale` 参数，这将仅允许用户搜索具有指定语言环境的页面。

```ts
import { useDocsSearch } from 'fumadocs-core/search/client';

const { search, setSearch, query } = useDocsSearch({
  type: 'fetch',
  locale: 'cn',
});
```

## 无头模式

您可以将搜索服务器托管在其他后端（如 Express 和 Elysia）上。

```ts
import { initAdvancedSearch } from 'fumadocs-core/search/server';

const server = initAdvancedSearch({
  // you still have to pass indexes
});

server.search('query', {
  // you can specify `locale` and `tag` here
});
```
