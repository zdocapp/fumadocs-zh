## 介绍

Algolia 集成会自动为文档搜索配置 Algolia Search。

它会为文档中的**每个段落**创建一条记录，这也是 Algolia 推荐的做法。

每条记录包含以下可搜索属性：

| 属性      | 描述              |
| --------- | ----------------- |
| `title`   | 页面标题          |
| `section` | 标题 ID（可为空） |
| `content` | 段落内容          |

`section` 字段仅存在于标题下的段落中。标题和段落会被索引为单独的记录，并按页面 ID 分组。

请注意，它期望页面的 `url` 属性是唯一的，您不应有两个具有相同 URL 的页面。

## 设置

安装依赖：

```package-install
algoliasearch
```

### 在 Algolia 上注册

注册并获取用于搜索的应用 ID 和 API 密钥。将这些凭据存储在环境变量中。

### 同步搜索索引

预渲染一个静态路由 `/static.json`，将搜索索引导出到生产构建中：

```ts title="lib/export-search-indexes.ts"
import { source } from '@/lib/source';
import type { DocumentRecord } from 'fumadocs-core/search/algolia';

export async function exportSearchIndexes() {
  const results: DocumentRecord[] = [];

  for (const page of source.getPages()) {
    results.push({
      _id: page.url,
      structured: page.data.structuredData,
      url: page.url,
      title: page.data.title,
      description: page.data.description,
    });
  }

  return results;
}
```

创建一个脚本来同步搜索索引：

```ts title="scripts/sync-content.ts" twoslash
import { algoliasearch } from 'algoliasearch';
import { sync, DocumentRecord } from 'fumadocs-core/search/algolia';
import * as fs from 'node:fs';

// the path of pre-rendered `static.json`, choose one according to your React framework
const filePath = {
  next: '.next/server/app/static.json.body',
  'tanstack-start': '.output/public/static.json',
  'react-router': 'build/client/static.json',
}['next'];

const content = fs.readFileSync(filePath);

const records = JSON.parse(content.toString()) as DocumentRecord[];

const client = algoliasearch('id', 'key');

// update the index settings and sync search indexes
void sync(client, {
  indexName: 'document',
  documents: records,
});
```

现在在构建后运行该脚本：

```json title="package.json"
{
  "scripts": {
    "build": "... && bun ./scripts/sync-content.ts"
  }
}
```

### 工作流程

您可以使用脚本手动上传搜索索引，或将其与 CI/CD 流水线集成。

### 搜索界面

您可以考虑不同的选项来实现用户界面：

- 使用 [Fumadocs UI 搜索对话框](/docs/ui/search/algolia)。
- 使用内置搜索客户端钩子构建自己的搜索功能：

  ```ts twoslash
  import { liteClient } from 'algoliasearch/lite';
  import { useDocsSearch } from 'fumadocs-core/search/client';

  const client = liteClient('id', 'key');

  const { search, setSearch, query } = useDocsSearch({
    type: 'algolia',
    indexName: 'document',
    client,
  });
  ```

- 直接使用他们的官方客户端。

## 选项

### 标签筛选

要配置标签筛选，请向索引添加 `tag` 值。

```ts title="lib/export-search-indexes.ts"
import { source } from '@/lib/source';
import type { DocumentRecord } from 'fumadocs-core/search/algolia';

export async function exportSearchIndexes() {
  const results: DocumentRecord[] = [];

  for (const page of source.getPages()) {
    results.push({
      _id: page.url,
      structured: page.data.structuredData,
      url: page.url,
      title: page.data.title,
      description: page.data.description,
      // [!code ++]
      tag: '<your value>',
    });
  }

  return results;
}
```

并更新您的搜索客户端：

- **Fumadocs UI**：在搜索界面上启用[标签筛选](/docs/ui/search/algolia#tag-filter)。
- **搜索客户端**：您可以像这样添加标签筛选器：

  ```ts
  import { useDocsSearch } from 'fumadocs-core/search/client';

  const { search, setSearch, query } = useDocsSearch({
    tag: '<your tag value>',
    // ...
  });
  ```

`tag` 字段是一个用于分面的属性。您也可以在 Algolia 搜索客户端上使用筛选器 `tag:value`。
