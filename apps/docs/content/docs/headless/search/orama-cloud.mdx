## REST API

REST API 集成需要您上传文档的索引。

在仪表板中使用以下模式创建一个新的 REST API 索引：

```json
{
  "id": "string",
  "title": "string",
  "url": "string",
  "tag": "string",
  "page_id": "string",
  "section": "string",
  "section_id": "string",
  "content": "string"
}
```

通过预渲染静态路由导出搜索索引。

```ts title="lib/export-search-indexes.ts"
import { source } from '@/lib/source';
import type { OramaDocument } from 'fumadocs-core/search/orama-cloud';

export async function exportSearchIndexes() {
  return source.getPages().map((page) => {
    return {
      id: page.url,
      structured: page.data.structuredData,
      url: page.url,
      title: page.data.title,
      description: page.data.description,
    } satisfies OramaDocument;
  });
}
```

然后，使用仪表板中的私有 API 密钥和索引 ID，创建一个脚本来同步搜索索引。

```ts title="scripts/sync-content.ts"
import { sync, type OramaDocument } from 'fumadocs-core/search/orama-cloud';
import * as fs from 'node:fs/promises';
import { CloudManager } from '@oramacloud/client';

// the path of pre-rendered `static.json`, choose one according to your React framework
const filePath = {
  next: '.next/server/app/static.json.body',
  'tanstack-start': '.output/public/static.json',
  'react-router': 'build/client/static.json',
}['next'];

async function main() {
  // private API key [!code highlight]
  const apiKey = process.env.ORAMA_PRIVATE_API_KEY;

  if (!apiKey) {
    console.log('no api key for Orama found, skipping');
    return;
  }

  const content = await fs.readFile(filePath);
  const records = JSON.parse(content.toString()) as OramaDocument[];
  const manager = new CloudManager({ api_key: apiKey });

  await sync(manager, {
    index: '<index>',
    documents: records,
  });

  console.log(`search updated: ${records.length} records`);
}

void main();
```

在生产构建后运行该脚本：

```json title="package.json"
{
  "scripts": {
    "build": "... && bun scripts/sync-content.ts"
  }
}
```

### 搜索客户端

要在客户端搜索文档，请考虑：

- 使用 [Fumadocs UI 搜索对话框](/docs/ui/search/orama-cloud)。
- 使用 Fumadocs 的内置钩子自定义搜索 UI：

  ```ts
  import { useDocsSearch } from 'fumadocs-core/search/client';
  import { OramaClient } from '@oramacloud/client';

  const client = new OramaClient();

  const { search, setSearch, query } = useDocsSearch({
    type: 'orama-cloud',
    client,
    params: {
      // 搜索参数
    },
  });
  ```

- 直接使用他们的搜索客户端。

## 网络爬虫

1. 从仪表板创建一个爬虫索引，并使用“文档”预设正确配置它。
2. 从仪表板复制公共 API 密钥和索引 ID

### 搜索客户端

与 REST API 集成相同，但请确保将 `index` 设置为 `crawler`。

```ts
import { useDocsSearch } from 'fumadocs-core/search/client';
import { OramaClient } from '@oramacloud/client';

const client = new OramaClient({
  endpoint: '<endpoint_url>',
  api_key: '<api_key>',
});

const { search, setSearch, query } = useDocsSearch({
  type: 'orama-cloud',
  index: 'crawler',
  client,
  params: {
    // optional search params
  },
});
```

对于 Fumadocs UI 也是如此。
