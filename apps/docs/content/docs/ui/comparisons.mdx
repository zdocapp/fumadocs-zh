## Nextra

Fumadocs 深受 Nextra 的启发。例如，路由约定。这就是为什么
`meta.json` 也存在于 Fumadocs 中。

Nextra 比 Fumadocs 更具规范性，因此，与简单地编辑配置文件相比，
您必须手动配置各项内容。

如果您希望对所有内容拥有更多控制权，例如将其添加到现有代码库中
或实现高级路由，Fumadocs 会表现得非常出色。

### 功能对比表

| 特性              | Fumadocs   | Nextra                   |
| ----------------- | ---------- | ------------------------ |
| 静态生成          | 是         | 是                       |
| 缓存              | 是         | 是                       |
| 亮色/暗色模式     | 是         | 是                       |
| 语法高亮          | 是         | 是                       |
| 目录              | 是         | 是                       |
| 全文搜索          | 是         | 是                       |
| 国际化(i18n)      | 是         | 是                       |
| 最后 Git 编辑时间 | 是         | 是                       |
| 页面图标          | 是         | 是，通过 `_meta.js` 文件 |
| RSC               | 是         | 是                       |
| 远程源            | 是         | 是                       |
| SEO               | 通过元数据 | 是                       |
| 内置组件          | 是         | 是                       |
| RTL 布局          | 是         | 是                       |

### 附加特性

通过第三方库（如 [TypeDoc](https://typedoc.org)）支持的特性不在此列出。

| 特性                | Fumadocs | Nextra |
| ------------------- | -------- | ------ |
| OpenAPI 集成        | 是       | 否     |
| TypeScript 文档生成 | 是       | 否     |
| TypeScript Twoslash | 是       | 是     |

## Mintlify

Mintlify 是一项文档服务，与 Fumadocs 相比，它提供免费套餐但并非完全免费和开源。

Fumadocs 不如 Mintlify 功能强大，例如 Mintlify 的 OpenAPI 集成。
作为 Fumadocs 的创建者，如果您对当前构建文档的方式感到满意，我不建议从 Mintlify 切换到 Fumadocs。
然而，我相信 Fumadocs 对于所有希望拥有优雅文档的 React.js 开发者来说都是一个合适的工具。

## Docusaurus

Docusaurus 是一个基于 React.js 的强大框架。它通过插件和自定义主题提供了许多出色的功能。

### 更低的复杂度

由于 Fumadocs 设计为与 React 框架集成，您可能需要更多 React.js 知识才能开始使用。
作为回报，Fumadocs 具有更好的可定制性。

对于简单的文档，如果您不需要任何框架特定功能，Docusaurus 可能是更好的选择。

### 插件

您可以通过插件轻松实现许多功能，其生态系统确实更大并由许多贡献者维护。

相比之下，Fumadocs 的灵活性允许您自行实现这些功能，可能需要更长时间才能调整到令您满意的程度。
