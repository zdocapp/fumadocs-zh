## 介绍

Fumadocs 为 MDX（一种标记语言）提供了许多有用的扩展。以下是 Fumadocs 默认 MDX 语法的简要介绍。

> MDX 并非 Fumadocs 唯一支持的格式。实际上，您可以使用任何渲染器，例如 `next-mdx-remote` 或 CMS。

## MDX

我们推荐使用 MDX，它是 Markdown 的超集，支持 JSX 语法。
它允许您导入组件，并在文档中使用它们，甚至编写 JavaScript。

参见：

- [MDX 语法](https://mdxjs.com/docs/what-is-mdx/#mdx-syntax)。
- 同时支持 GFM（GitHub Flavored Markdown），请参阅 [GFM 规范](https://github.github.com/gfm)。

```mdx
---
title: This is a document
---

import { Component } from './component';

<Component name="Hello" />

# Heading

## Heading

### Heading

#### Heading

Hello World, **Bold**, _Italic_, ~~Hidden~~

1. First
2. Second
3. Third

- Item 1
- Item 2

> Quote here

![alt](/image.png)

| Table | Description |
| ----- | ----------- |
| Hello | World       |
```

### 自动链接

内部链接使用您 React 框架（例如 `next/link`）的 `<Link />` 组件，以实现预取并避免硬重载。

外部链接将默认添加 `rel="noreferrer noopener" target="_blank"` 属性以确保安全。

```mdx
[My Link](https://github.github.com/gfm)

This also works: https://github.github.com/gfm.
```

#### “进一步阅读”部分

您可以执行如下操作：

```tsx title="page.tsx"
import { getPageTreePeers } from 'fumadocs-core/server';
import { source } from '@/lib/source';

<Cards>
  {getPageTreePeers(source.pageTree, '/docs/my-page').map((peer) => (
    <Card key={peer.url} title={peer.name} href={peer.url}>
      {peer.description}
    </Card>
  ))}
</Cards>;
```

这将显示同一文件夹中的其他页面作为卡片。

### 提示框

适用于添加提示/警告，默认包含。您可以指定提示框的类型：

- `info`（默认）
- `warn`/`warning`
- `error`
- `success`

```mdx
<Callout>Hello World</Callout>

<Callout title="Title">Hello World</Callout>

<Callout title="Title" type="error">
  Hello World
</Callout>
```

<Callout>Hello World</Callout>

<Callout title="Title" type="warn">
  Hello World
</Callout>

<Callout title="Title" type="error">
  Hello World
</Callout>

### 标题

每个标题都会自动应用锚点，它会清理无效字符（如空格）。（例如将 `Hello World` 转换为 `hello-world`）

```md
# Hello `World`
```

#### 目录设置

目录（TOC）将根据标题生成，你也可以自定义标题的效果：

```md
# Heading [!toc]

This heading will be hidden from TOC.

# Another Heading [toc]

This heading will **only** be visible in TOC, you can use it to add additional TOC items.
Like headings rendered in a React component:

<MyComp />
```

#### 自定义锚点

你可以添加 `[#slug]` 来自定义标题锚点。

```md
# heading [#my-heading-id]
```

你还可以将其与目录设置链式使用，例如：

```md
# heading [toc] [#my-heading-id]
```

要将用户链接到特定标题，请在哈希片段中添加标题 ID：`/page#my-heading-id`。

### 代码块

默认支持使用 [Rehype Code](/docs/headless/mdx/rehype-code) 进行语法高亮。

````mdx
```js
console.log('Hello World');
```

```js title="My Title"
console.log('Hello World');
```
````

#### 行号

显示行号，它也可以与 Twoslash 和其他转换器一起使用。

````mdx tab="Input"
```ts twoslash lineNumbers
const a = 'Hello World';
//    ^?
console.log(a); // [!code highlight]
```
````

```ts twoslash lineNumbers tab="Output"
const a = 'Hello World';
//    ^?
console.log(a); // [!code highlight]
```

你可以设置行号的初始值。

````mdx tab="Input"
```js lineNumbers=4
function main() {
  console.log('starts from 4');

  return 0;
}
```
````

```js lineNumbers=4 tab="Output"
function main() {
  console.log('starts from 4');

  return 0;
}
```

#### Shiki 转换器

我们支持部分 [Shiki 转换器](https://shiki.style/packages/transformers)，允许你高亮/样式化特定行。

````md tab="Input"
```tsx
// highlight a line
<div>Hello World</div> // [\!code highlight]

// highlight a word
// [\!code word:Fumadocs]
<div>Fumadocs</div>

// diff styles
console.log('hewwo'); // [\!code --]
console.log('hello'); // [\!code ++]

// focus
return new ResizeObserver(() => {}) // [\!code focus]
```
````

```tsx tab="Output"
// highlight a line
<div>Hello World</div> // [!code highlight]

// highlight a word
// [!code word:Fumadocs]
<div>Fumadocs</div>

// diff styles:
console.log('hewwo'); // [!code --]
console.log('hello'); // [!code ++]

// focus
return new ResizeObserver(() => {}) // [!code focus]
```

````mdx
```ts tab="Tab 1"
````

虽然默认禁用，但你可以通过配置 remark 插件在标签值中使用 MDX：

```ts tab="Fumadocs MDX" title="source.config.ts"
import { defineConfig } from 'fumadocs-mdx/config';

export default defineConfig({
  mdxOptions: {
    remarkCodeTabOptions: {
      parseMdx: true, // [!code ++]
    },
  },
});
```

```ts tab="MDX Compiler"
import { compile } from '@mdx-js/mdx';
import { remarkCodeTab } from 'fumadocs-core/mdx-plugins';

await compile('...', {
  remarkPlugins: [
    [
      remarkCodeTab,
      {
        parseMdx: true, // [!code ++]
      },
    ],
  ],
});
```

### 包含

> 此功能仅在 **Fumadocs MDX** 中可用。

引用另一个文件（也可以是 Markdown/MDX 文档）。
在 `<include>` 标签中指定目标文件路径（相对于 MDX 文件本身）。

```mdx title="page.mdx"
<include>./another.mdx</include>
```

查看 [include 的其他用法](/docs/mdx/include)。

### NPM 命令

用于生成不同包管理器安装包的命令。

````md tab="Input"
```npm
npm i next -D
```
````

```npm tab="Output"
npm i next -D
```

使用 Fumadocs MDX 时，您可以像这样进行自定义：

```tsx title="source.config.ts"
import { defineConfig } from 'fumadocs-mdx/config';

export default defineConfig({
  mdxOptions: {
    remarkNpmOptions: {
      // ...
    },
  },
});
```
