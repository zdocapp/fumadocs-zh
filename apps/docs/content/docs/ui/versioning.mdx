## 概述

开发者工具相关的文档通常需要进行版本管理，例如为同一工具的 v1 和 v2 版本提供不同的文档。

Fumadocs 提供了基础工具，让您能够以自己的方式实现版本管理。

## 部分版本管理

当版本管理仅适用于文档的部分内容时，您可以通过文件夹进行分隔。

例如：

<Files>
  <Folder name="java-sdk" defaultOpen>
    <Folder name="v1" defaultOpen>
      <File name="getting-started.mdx" />
    </Folder>
    <Folder name="v2" defaultOpen>
      <File name="getting-started.mdx" />
    </Folder>
  </Folder>
</Files>

<Callout title="Good to Know">
  You may want to group them with tabs rather than folders [using Sidebar
  Tabs](/docs/ui/navigation/sidebar#sidebar-tabs).
</Callout>

## 完整版本管理

有时您希望对整个网站进行版本管理，例如 https://v14.fumadocs.dev (Fumadocs v14) 和 https://fumadocs.dev (最新版 Fumadocs)。

您可以为某个版本的文档创建一个 Git 分支（例如命名为 `v2`），并将其作为独立应用部署到另一个子域名上，如 `v2.my-site.com`。

可选地，您可以从文档中链接到其他版本。
这种设计相比部分版本管理具有一些优势：

- 易于维护：当您迭代或升级依赖时，旧文档/分支不会受到影响。
- 更好的一致性：不仅是文档本身，您的着陆页（和其他页面）也会进行版本管理。
