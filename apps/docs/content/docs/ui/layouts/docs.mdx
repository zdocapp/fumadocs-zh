## 使用方法

将您的页面树传递给该组件。

```tsx title="layout.tsx"
import { DocsLayout } from 'fumadocs-ui/layouts/docs';
import { baseOptions } from '@/lib/layout.shared';
import type { ReactNode } from 'react';

export default function Layout({ children }: { children: ReactNode }) {
  return (
    <DocsLayout {...baseOptions()} tree={tree}>
      {children}
    </DocsLayout>
  );
}
```

## 导航栏

仅限移动端的导航栏，`nav` 属性也可在其他 Fumadocs 布局中重复使用。

<div className='max-w-[460px] mx-auto'>

![Docs Nav](/docs/docs-nav.png)

</div>

```tsx
import { DocsLayout } from 'fumadocs-ui/layouts/docs';
import { baseOptions } from '@/lib/layout.shared';
import type { ReactNode } from 'react';

export default function Layout({ children }: { children: ReactNode }) {
  const base = baseOptions();

  return (
    <DocsLayout
      {...base}
      nav={{
        ...base.nav,
        // override
      }}
    >
      {children}
    </DocsLayout>
  );
}
```

### 透明模式

要使导航栏背景透明，您可以配置透明模式。

```tsx
import type { BaseLayoutProps } from 'fumadocs-ui/layouts/shared';

export const baseOptions: BaseLayoutProps = {
  nav: {
    transparentMode: 'top',
  },
};
```

| 模式     | 描述                 |
| -------- | -------------------- |
| `always` | 始终使用透明背景     |
| `top`    | 当位于页面顶部时     |
| `none`   | 禁用透明背景（默认） |

### 替换导航栏

要替换 Docs Layout 中的导航栏，将 `nav.component` 设置为您自己的组件。

```tsx title="layout.tsx"
import { baseOptions } from '@/lib/layout.shared';
import { DocsLayout } from 'fumadocs-ui/layouts/notebook';
import type { ReactNode } from 'react';

export default function Layout({ children }: { children: ReactNode }) {
  return (
    <DocsLayout
      {...baseOptions()}
      nav={{
        component: <CustomNavbar />,
      }}
    >
      {children}
    </DocsLayout>
  );
}
```

Fumadocs 使用 **CSS 变量** 来共享布局组件的尺寸，并将每个布局组件适配到适当的位置。

您需要将 `--fd-nav-height` 覆盖为您自定义导航栏的确切高度，这可以通过 CSS 样式表（例如在 `global.css` 中）完成：

```css
:root {
  --fd-nav-height: 80px !important;
}
```

## 高级

### 禁用预取

默认情况下，它使用您 React 框架的 `<Link />` 组件并启用预取功能。

在 Vercel 上，预取请求可能导致无服务器函数和数据缓存的使用量增加。
它也可能达到其他一些托管平台的限制。

您可以禁用预取功能以减少预取请求的数量。

```tsx
import { DocsLayout } from 'fumadocs-ui/layouts/docs';

<DocsLayout sidebar={{ prefetch: false }} />;
```
