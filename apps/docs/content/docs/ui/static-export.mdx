## 概述

默认情况下，Fumadocs 采用服务器优先的方法，始终需要运行服务器来提供服务。

您也可以通过在自己的 React 框架上启用静态构建来输出静态网站。

### Next.js

Fumadocs 与 Next.js 静态导出完全兼容，允许您将应用导出为静态 HTML 站点，无需 Node.js 服务器。

```js title="next.config.mjs"
/**
 * @type {import('next').NextConfig}
 */
const nextConfig = {
  output: 'export',

  // Optional: Change links `/me` -> `/me/` and emit `/me.html` -> `/me/index.html`
  // trailingSlash: true,

  // Optional: Prevent automatic `/me` -> `/me/`, instead preserve `href`
  // skipTrailingSlashRedirect: true,
};
```

有关限制和详细信息，请参阅 [Next.js 文档](https://nextjs.org/docs/app/guides/static-exports)。

### React Router

通过配置所有页面的预渲染，您可以将 `build/client` 目录作为静态网站提供服务。

```ts title="react-router.config.ts"
import type { Config } from '@react-router/dev/config';
import { glob } from 'node:fs/promises';
import { createGetUrl, getSlugs } from 'fumadocs-core/source';

const getUrl = createGetUrl('/docs');

export default {
  ssr: true,
  async prerender({ getStaticPaths }) {
    const paths: string[] = [...getStaticPaths()];

    for await (const entry of glob('**/*.mdx', { cwd: 'content/docs' })) {
      paths.push(getUrl(getSlugs(entry)));
    }

    return paths;
  },
} satisfies Config;
```

### Tanstack Start

Tanstack Start 具有强大的自动预渲染功能，可自动爬取您的页面。

```ts title="vite.config.ts"
import react from '@vitejs/plugin-react';
import { tanstackStart } from '@tanstack/react-start/plugin/vite';
import { defineConfig } from 'vite';

export default defineConfig({
  server: {
    port: 3000,
  },
  plugins: [
    // ...other plugins
    tanstackStart({
      // [!code ++:4]
      target: 'static',
      prerender: {
        enabled: true,
      },
      // if you have any hidden paths that's not visible on UI, you can add them explicitly.
      pages: [
        {
          path: '/docs/test',
        },
      ],
      customViteReactPlugin: true,
    }),
    react(),
  ],
});
```

## 搜索

### 内置搜索

您需要额外的配置来静态存储搜索索引，并且搜索将在浏览器端进行计算：

1. **搜索客户端：** [启用静态模式](/docs/ui/search/orama#static)。
2. **搜索服务器：** [输出静态索引](/docs/headless/search/orama#static-export)。

### 云解决方案

由于搜索功能由远程服务器提供支持，静态导出无需配置即可工作。
