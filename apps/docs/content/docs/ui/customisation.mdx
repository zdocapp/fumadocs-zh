### 组件

Fumadocs UI 还为交互式示例提供了样式化组件，以增强您的文档，您可以通过 `style` 和 `className` 等公开属性来自定义它们。

请参阅[组件](/docs/ui/components)。

### 设计系统

由于设计系统基于 Tailwind CSS 构建，您可以通过 [CSS 变量](/docs/ui/theme#colors) 来自定义它。

### CLI

Fumadocs CLI 是一个将组件安装到代码库的工具，类似于 Shadcn UI。

```package-install
npx @fumadocs/cli
```

使用它来安装 Fumadocs UI 组件：

```package-install
npx @fumadocs/cli add
```

或自定义布局：

```package-install
npx @fumadocs/cli customise
```
