## 使用方法

基于
[Radix UI Accordion](https://www.radix-ui.com/primitives/docs/components/accordion)，适用于常见问题解答部分。

```mdx
import { Accordion, Accordions } from 'fumadocs-ui/components/accordion';

<Accordions type="single">
  <Accordion title="My Title">My Content</Accordion>
</Accordions>
```

### 链接到手风琴式折叠面板

您可以为手风琴式折叠面板指定一个 `id`。当用户通过哈希参数导航到带有指定 `id` 的页面时，该折叠面板将自动展开。

```mdx
<Accordions>
<Accordion title="My Title" id="my-title">

My Content

</Accordion>
</Accordions>
```

> 手风琴式折叠面板的值默认与标题相同。当存在 id 时，将使用 id 作为值。
