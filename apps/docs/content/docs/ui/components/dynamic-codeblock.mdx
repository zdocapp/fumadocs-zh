## 使用方法

### 客户端组件

```tsx
import { DynamicCodeBlock } from 'fumadocs-ui/components/dynamic-codeblock';

<DynamicCodeBlock lang="ts" code='console.log("Hello World")' />;
```

与 MDX [`CodeBlock`](/docs/ui/mdx/codeblock) 组件不同，这是一个客户端组件，无需 MDX 即可使用。
它使用 Shiki 对代码进行高亮显示，并使用默认组件进行渲染。

特性：

- 可在服务器端预渲染
- 在浏览器中按需懒加载语言和主题

#### 选项

```tsx
import { DynamicCodeBlock } from 'fumadocs-ui/components/dynamic-codeblock';

<DynamicCodeBlock
  lang="ts"
  code='console.log("Hello World")'
  options={{
    themes: {
      light: 'github-light',
      dark: 'github-dark',
    },
    components: {
      // override components (e.g. `pre` and `code`)
    },
    // other Shiki options
  }}
/>;
```

### 服务端组件

如需服务端组件等效方案，您可以使用核心内置工具：
