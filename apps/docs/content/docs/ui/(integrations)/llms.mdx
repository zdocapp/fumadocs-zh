## 面向大语言模型的文档

您可以通过专门为大语言模型准备的文档内容，使您的文档站点更加 AI 友好。

首先，创建一个 `getLLMText` 函数，将页面转换为静态 MDX 内容：

<include meta='title="lib/get-llm-text.ts"'>./get-llm-text.ts</include>

> 修改它以包含其他 remark 插件。

### `llms-full.txt`

供 AI 阅读的文档版本。

<include meta='tab="Next.js" title="app/llms-full.txt/route.ts"'>
  ./llms.txt.ts
</include>

```ts tab="React Router" title="app/routes/llms-full.ts"
// make sure to include this route in `routes.ts` & pre-rendering!
import { source } from '@/lib/source';
import { getLLMText } from '@/lib/get-llm-text';

export async function loader() {
  const scan = source.getPages().map(getLLMText);
  const scanned = await Promise.all(scan);

  return new Response(scanned.join('\n\n'));
}
```

```ts tab="Tanstack Start" title="src/routes/llms-full[.]txt.ts"
import { createServerFileRoute } from '@tanstack/react-start/server';
import { source } from '@/lib/source';
import { getLLMText } from '@/lib/get-llm-text';

export const ServerRoute = createServerFileRoute('/llms-full.txt').methods({
  GET: async () => {
    const scan = source.getPages().map(getLLMText);
    const scanned = await Promise.all(scan);
    return new Response(scanned.join('\n\n'));
  },
});
```

### `*.mdx`

允许用户在页面 URL 后追加 `.mdx` 来获取其 Markdown/MDX 内容。

在 Next.js 中，您可以创建一个路由处理程序来返回页面内容，并将用户重定向到该路由。

<include meta='tab="app/llms.mdx/[[...slug]]/route.ts"'>./llms.mdx.ts</include>

```ts tab="next.config.ts"
import type { NextConfig } from 'next';

const config: NextConfig = {
  async rewrites() {
    return [
      {
        source: '/docs/:path*.mdx',
        destination: '/llms.mdx/:path*',
      },
    ];
  },
};
```

### 页面操作

AI 的常用页面操作，需要先实现 `*.mdx` 功能。

![AI 页面操作](/docs/ai-page-actions.png)

```npm
npx @fumadocs/cli add ai-page-actions
```

在您的文档页面中这样使用：

```tsx title="app/docs/[[...slug]]/page.tsx"
<div className="flex flex-row gap-2 items-center border-b pt-2 pb-6">
  <LLMCopyButton markdownUrl={`${page.url}.mdx`} />
  <ViewOptions
    markdownUrl={`${page.url}.mdx`}
    githubUrl={`https://github.com/${owner}/${repo}/blob/dev/apps/docs/content/docs/${page.path}`}
  />
</div>
```

## AI 搜索

![AI 搜索](/docs/ai-search.png)

您可以使用 Fumadocs CLI 安装 AI 搜索对话框：

```package-install
npx @fumadocs/cli add ai-search
```

默认情况下，它配置为使用 Inkeep AI。由于它是通过 Vercel AI SDK 连接的，您可以轻松连接到自己的 AI 模型。

> [!NOTE]
> 请注意 Fumadocs 不提供 AI 模型，这取决于您自己。
