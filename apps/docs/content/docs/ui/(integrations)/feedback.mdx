## 概述

反馈对于了解读者的想法至关重要，能帮助您进一步改进文档内容。

## 安装

添加依赖项：

```package-install
class-variance-authority lucide-react
```

复制组件：

<include cwd meta='title="components/rate.tsx"'>
  ./components/rate.tsx
</include>

`@/lib/cn` 导入标识符可能因项目而异，如果需要，请将其更改为导入您的 `cn()` 函数（例如像 `@/lib/utils`）。

### 使用方法

现在将 `<Rate />` 组件添加到您的文档页面：

```tsx
import { DocsPage } from 'fumadocs-ui/page';
import { Rate } from '@/components/rate';
import posthog from 'posthog-js';

export default async function Page() {
  return (
    <DocsPage toc={toc} full={page.data.full}>
      {/* at the bottom of page */}
      <Rate
        onRateAction={async (url, feedback) => {
          'use server';

          await posthog.capture('on_rate_docs', feedback);
        }}
      />
    </DocsPage>
  );
}
```

在上面的示例中，它通过在 PostHog 上捕获 `on_rate_docs` 事件来报告用户反馈。

您可以指定自己的服务器操作到 `onRateAction`，并将反馈报告到不同的目的地，如数据库或通过其 API 到 GitHub Discussions。

### 链接到 GitHub Discussion

要将您的反馈报告到 GitHub Discussion，请创建一个自定义的 `onRateAction`。

您可以复制此示例作为起点：

<include cwd meta="lib/github.ts">
  ./lib/github.ts
</include>

- 创建您自己的 GitHub App 并获取其应用 ID 和私钥。
- 填写所需的环境变量。
- 替换常量，如 `owner`、`repo` 和 `DocsCategory`。
