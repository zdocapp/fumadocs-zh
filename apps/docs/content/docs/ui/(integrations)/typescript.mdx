## 使用方法

```package-install
fumadocs-typescript
```

### UI 集成

它附带 `AutoTypeTable` 组件。了解更多关于 [Auto Type Table](/docs/ui/components/auto-type-table) 的信息。

### MDX 集成

您可以将其用作 remark 插件：

```ts title="source.config.ts" tab="Fumadocs MDX"
import { remarkAutoTypeTable, createGenerator } from 'fumadocs-typescript';
import { defineConfig } from 'fumadocs-mdx/config';

const generator = createGenerator();

export default defineConfig({
  mdxOptions: {
    remarkPlugins: [[remarkAutoTypeTable, { generator }]],
  },
});
```

```ts tab="MDX Compiler"
import { remarkAutoTypeTable, createGenerator } from 'fumadocs-typescript';
import { compile } from '@mdx-js/mdx';

const generator = createGenerator();

await compile('...', {
  remarkPlugins: [[remarkAutoTypeTable, { generator }]],
});
```

它为您提供了一个 `auto-type-table` 组件。

您可以像使用 [Auto Type Table](/docs/ui/components/auto-type-table) 一样使用它，但有一些额外的规则：

- 属性值必须是字符串。
- `path` 接受相对于 MDX 文件本身的路径。
- 您还需要将 [`TypeTable`](/docs/ui/components/type-table) 添加到 MDX 组件中。

```ts title="path/to/file.ts"
export interface MyInterface {
  name: string;
}
```

```mdx title="page.mdx"
<auto-type-table path="./path/to/file.ts" name="MyInterface" />
```

## 注解

### 隐藏

通过添加 `@internal` tsdoc 标签来隐藏字段。

```ts
interface MyInterface {
  /**
   * @internal
   */
  cache: number;
}
```

### 指定类型名称

您可以使用 `@remarks` tsdoc 标签指定类型的名称。

```ts
interface MyInterface {
  /**
   * @remarks `timestamp` Returned by API. // [!code highlight]
   */
  time: number;
}
```

这将使 `time` 属性的类型显示为 `timestamp`。
